This documentation tree only contains material intended to stay with the public product repository.

## Sections

- `engineering/` contains implementation architecture, content model references, engineering patterns, and technical reference docs.
- `design/` contains UX principles, notification guidance, review material, and UI behavior references.
- `overview.md` gives the high-level map for external readers.

## Rules Of Thumb

- Private ops, infra state, and market research belong outside this public repository.
- Keep public docs focused on architecture, setup, and contributor-facing behavior.
